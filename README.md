# 星际手记 · 宇宙探索

作者 QQ：2287147617；微信：chengzhiwo。

独立设计的中文宇宙科普网站，包含太阳系、银河系、黑洞三维科学示意，18 篇天体档案、距离刻度、宇宙时间线和常见问题。

在 HTTPS 浏览器中开启摄像头：单手张开拉远、握拳靠近、半张停止缩放、左右移动转动视角。识别使用本地部署的 MediaPipe 模型与 Web Worker；不上传摄像头画面。关闭功能、切到后台或离开页面会停止摄像头。支持鼠标拖拽、滚轮及双指缩放。

天体尺寸、轨道与运行速度经过压缩，星系与黑洞为概念可视化，不是真实照片或实时星历。科普来源链接在各篇档案内。

本地验证：Edge 桌面/390px 手机视窗交互通过，识别引擎初始化、模拟摄像头无手状态、权限拒绝与关闭设备通过。真实单手准确率及大陆各运营商访问尚未验证。

Three.js 使用 MIT 许可；MediaPipe 使用 Apache 2.0 许可，许可文本位于 vendor/。这些第三方组件及科学资料不属于作品作者原创部分。
